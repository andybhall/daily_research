A collector's archive of LLM jailbreaks

22 months of git history from one hobbyist's vendor-by-vendor collection of prompts that jailbreak AI models.

August 14, 2026
22/25
Willis score

The AI-focus gate makes this frontier tricky: the obvious AI-generation hoards (Civitai, DiffusionDB) are already being mined hard. The freshest thing is a single person's obsessively-maintained archive.

Top find: L1B3RT4S jailbreak hoard (elder-plinius / "Pliny")

A public GitHub repo hoarding working jailbreak prompts for frontier LLMs, organized one file per AI vendor, continuously updated for ~two years (repo). It is the canonical hobbyist artifact of the AI red-team subculture.

AI nexus + agenda. Adversarial prompts that defeat model guardrails — squarely Governance (the governance and robustness of the AI systems that increasingly mediate political information), with an Information edge (manipulation of AI outputs). AI nexus intrinsic.

Why it clears the bar. Real jailbreaks that actually work, published under community-cred stakes (a); accumulated incidentally over 22 months of commits (b); panel-able by vendor × time via git history (d). Unclaimed (c≈4): the academic jailbreak datasets (verazuo, CCS'24; TrustAIRLab "In-The-Wild") scraped Reddit/Discord — this curated vendor-organized hoard, and especially its commit timeline, is essentially unstudied as a dataset.

Evidence from a live sample. I cloned it today and analyzed structure + history only (no prompt content): 39 vendor-specific files — one each for OpenAI, Anthropic, Google, Meta, Mistral, DeepSeek, xAI, Midjourney, Cohere, NVIDIA, Amazon, Microsoft, Alibaba, Moonshot, and more — across 253 commits spanning 2024-04-08 → 2026-02-17, with a burst of 33 commits in Feb 2025. That commit stream is a per-vendor timeline of the jailbreak commons. Artifacts in analysis/2026-08-14/.

Access & cost. Plain public git; a weekend to structure. Nearest work / difference: existing jailbreak datasets are static Reddit/Discord scrapes measuring what jailbreaks exist; nobody uses this hoard's git history to measure the dynamics — per-vendor jailbreak cadence, persistence, and how fast each lab's guardrails force new techniques. Headline figure: vendor × month heatmap of jailbreak commits, 2024→2026, as a proxy for the guardrail arms race. Score: 22/25 (a5 b4 c4 d4 e5).

Runner-ups

Civitai community model archive. The largest open community for Stable-Diffusion checkpoints/LoRAs, with a public REST API exposing per-model downloads, licenses, base-model lineage, tips, and a poi real-person-likeness flag (API). Probed today: top-100 models are 65 checkpoints / 17 LoRAs; base-model lineage SD 1.5 (60) → SDXL (24) → Pony (24) → Flux; top model 2.3M downloads; 25.1M "buzz" tips across the sample. Honest caveat: heavily mined already — abusive-use/NSFW/deepfake papers plus released derivative datasets (Civiverse 6.5M; ImageGem 40.6M), so c≈2; the unworked edge is licensing choices × real-person poi × the creator economy, not NSFW prevalence. Information (synthetic media/deepfakes). Score: 21/25 (a5 b5 c2 d5 e4).

Pixiv AI-generated artwork archive. The hobbyist art platform where users tag AI-generated works — one study catalogued 15,203,948 artworks, 2,475,485 (16.2%) tagged AI-generated (arXiv 2402.18463). A collector hoard revealing the human-vs-AI creative mix and how communities label synthetic media; panel-able by artist over time. Access is via Pixiv's auth-gated API and one paper exists, so c≈3. Information. Score: 19/25 (a4 b4 c3 d4 e4).
