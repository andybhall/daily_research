Revisiting frontier 4 (08-12 took HF Hub, the DSA Transparency DB, and Community Notes — the model, moderation, and crowd layers). Today's distinct layer: the tools AI agents call.

Top find: MCP (Model Context Protocol) server registries

MCP is the 2025-26 standard that lets AI agents call external tools/data; the servers are catalogued in a canonical registry (registry.modelcontextprotocol.io, backed by Anthropic/GitHub/PulseMCP/Microsoft) plus marketplaces on top (Glama ~37k, mcp.so ~20k, PulseMCP ~12k, Smithery ~7k).

AI nexus + agenda. The capability/tool infrastructure of AI agents — Governance/Information (what systems and data AI agents get wired into, and how that layer is verified/secured), AI nexus intrinsic.

Why it clears the bar. Servers published under real developer stakes, revealing what the agent ecosystem actually builds (a); registries + version records accreting continuously — PulseMCP hand-reviewed daily since launch week (b); panel-able by server × version × time (d); on-agenda (e4). Unclaimed (c≈3): security/measurement papers exist (arXiv 2503.23278, 2506.13538, 2509.25292 "MCPCrawler"), but the registry as a longitudinal capability-and-governance panel is under-built.

Evidence from a live sample. An independent May-2026 pull counted 9,652 servers / 28,959 server-version records; 15,926 GitHub repos carry the mcp-server topic. Querying the official API today (/v0/servers, paginable): I pulled a bounded 500-server sample — every record is version-stamped (a real server × version panel), with reverse-DNS namespaces showing heavy publisher concentration (ai.bowmark alone = 191 servers in the alphabetical "a" slice). Honest caveat: the 500 are alphabetically ordered, so counts aren't registry-representative. Sample + breakdown in analysis/2026-09-01/. Score: 21/25 (a4 b5 c3 d5 e4).

Access & cost. Free official API (versioned, namespace-verified) + marketplace APIs; a weekend to snapshot, a cron to build the version time-series. Nearest work / difference: papers audit MCP security snapshots; nobody tracks the evolution — which capabilities (payments, browsing, data access) proliferate, and how verification/security governance lags the growth. Headline figure: monthly new MCP servers by capability class (data access vs. action-taking), 2025→2026.

Runner-ups

AI Agent Marketplace Index (DeepNLP, Hugging Face). A metadata dataset of AI agents — name, website, description, plus monthly web-performance metrics (Google/Bing rankings, GitHub stars, arXiv references) (HF). HF-hosted and probe-able; a panel of the agent economy's supply and visibility. Curated-aggregation caveat. Score: 18/25 (a3 b4 c3 d4 e4).

AI-provider Usage-Policy / AUP change tracking. How AI companies revise permissible use over time — Anthropic's Acceptable-Use-Policy → "Usage Policy" updates adding high-risk-use requirements (Anthropic), OpenAI's 2024 removal of its military-use ban. Governance of AI self-regulation, including political and military uses. Honest caveat: no clean public diff-tracker exists — assemblable from Wayback (a ledger seed) + providers' policy pages. Score: 18/25 (a4 b3 c4 d3 e5).
